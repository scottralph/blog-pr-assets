# blog-pr-assets

Public host for before/after screenshots referenced from pull requests in the (private) `scottralph/website` repo.

GitHub can only inline-render PR images from a public source, so screenshots live here and are referenced via raw.githubusercontent.com URLs.

Convention: files are named `issue-<N>-before.png` / `issue-<N>-after.png`. Each new PR removes older images (prune) and adds its own.
